INCLUDED ASSETS
================================================================================

USER-GENERATED VIDEOS
- Videos are generated on-demand via Fashn.ai API
- Generated videos are stored as temporary links in the database
- Automatic expiration: 48 hours after generation
- Cleanup: Expired videos are automatically deleted from the database

VIDEO LIFECYCLE
1. User uploads fashion image and configures video generation
2. Payment is processed via Stripe
3. Video is generated by Fashn.ai API
4. Video link is stored in database with created_at timestamp
5. expires_at is set to created_at + 48 hours
6. Automatic cleanup job runs every hour and deletes expired video records
7. User can manually delete their videos anytime

DATABASE STORAGE
- Only video metadata (link, creation time, expiration time) is stored
- Storage is minimal - just links and timestamps, not video files
- Soft delete is used (expired records marked with deleted_at timestamp)
- No permanent storage - all records are temporary

IMPORTANT CONSIDERATIONS
- Generated videos are NOT archived or kept permanently
- Users must download their videos within 48 hours
- Once deleted, video links cannot be recovered
- No video files are stored on the server - only links to Fashn.ai URLs
- Database storage includes: video_url, created_at, expires_at, email
- Buyers are responsible for informing users about the 48-hour expiration
